Как работает указатель в C++

Пошагово исследуй разницу между number, &number, ptr и *ptr.

Пример программы

int number = 10;
int* ptr = &number;
cout << number << '\n';
cout << &number << '\n';
cout << ptr << '\n';
cout << *ptr << '\n';
