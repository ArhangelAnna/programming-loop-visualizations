Интерактивная модель · Массивы

Индекс — это место, значение — это содержимое

Нажми на ячейку массива или выбери индекс. Посмотри, какой элемент находится по этому индексу. Затем попробуй изменить значение элемента.

Выбери язык примера
int[] grades = { 5, 4, 5, 3 };

Массив grades

Размер = 4 · индексы 0–3
Цифра над ячейкой — индекс. Крупное число внутри — значение элемента.
Выбери индекс:
Console.WriteLine(grades[0]);
Выбран индекс 0. Нажми «Прочитать элемент».

Первый элемент расположен под индексом 0, а не 1.

Это визуальная модель работы массивов, а не запуск компилятора. Доступ к несуществующему индексу в C# приводит к исключению, а для обычного массива C++ — к неопределённому поведению.
