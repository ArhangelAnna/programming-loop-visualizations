Адрес переменной в C++

Пошагово сравниваем значение number и адрес &number.

Учебная модель памяти

Программа C++

1int number = 10;
2cout << number << '\n';
3cout << &number << '\n';
4number = 25;
5cout << number << '\n';
6cout << &number << '\n';
number→ значение&number→ адрес
Заметь: после изменения number меняется его значение, а адрес той же переменной в рамках этого примера остаётся прежним.
