Как указатель изменяет переменную

C++ · Разыменование и запись через *ptr. Нажимай «Дальше», чтобы проследить каждый шаг.

Фрагмент программы
C++ · активная инструкция подсвечивается
int number = 10;
int* ptr = &number;
cout << number << '\n';
*ptr = 25;
cout << number << '\n';
number = 40;
cout << *ptr << '\n';

Нажми «Дальше», чтобы создать переменную number.
Запомни: запись *ptr = 25; меняет объект number, а не адрес внутри ptr. Запись number = 40; тоже меняет тот же объект. Поэтому последующее чтение через *ptr возвращает 40.

Адреса 0x1000 и 0x2000 используются только для иллюстрации. Это не настоящие адреса процесса.
